# Radiant Group HQM V2.1 — GitHub Pages Demo

DEMO ONLY. All activity is synthetic. Names and demo credentials are embedded in the HTML; obtain permission before public publication. Do not enter real sales, GPS or photos. Authentication, hierarchy and audit are client-side only.

## Deploy
1. Create a repository (e.g. radiant-hqm-dashboard).
2. Upload index.html and .nojekyll to repository root on main.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Open the URL displayed by GitHub Pages.

## Smoke test
Select each demo account, sign in, verify hierarchy and filters, open both reports, print to PDF, return to dashboard. Test admin weights, FF inputs, persistence after reload and mobile layout. Browser automation was blocked by environment policy.

Local storage is per browser and origin; existing local file data will not automatically migrate. Initial dataset is about 3.05 MB; photos may exceed browser quota. No cloud database or production security.
